## Local demo runbook

1. Configure `.env` with PostgreSQL and independent random `SESSION_SECRET` / `DEMO_OPERATOR_KEY` values of at least 32 bytes. Do not expose or commit these secrets.
2. Run `npm run db:deploy`, then `npm run db:seed`, then `npm run dev`.
3. Visit `/login`; choose Auditor and review baseline A–E.
4. Choose HR for Company B, open worker B-001, correct fixed allowance to `500000` and reported base to `5581000` for `2026-09`.
5. Visit `/demo`, authenticate as the operator, recalculate `2026-09`; return through `/login` and Auditor. Verify Company B changes from `30/MEDIUM` to `0/LOW` and assessment history remains.
6. As Worker A, view contract/history and contribution mismatch. Submit P1 feedback; note the linked-feedback notice.
7. As Worker D, submit three categorical P5 reports (each new submission gets its own UUID). Counts below 3 stay suppressed. Recalculate as operator and verify Company D receives P5 `10/LOW`.
8. Close with the limitations: synthetic dataset, mock BPJS, company-period status, and human review required.

For presenter timing, perform one clean-reset run before demo. M6 still requires two clean-reset rehearsals and backup screenshots/video.
